# Security Policy

## Supported versions

Security fixes are evaluated against the most recent published stable release and the maintained `main` branch. Earlier release lines are not guaranteed ongoing backports. Confirm the current release on [GitHub Releases](https://github.com/rushairer/gouno-cli/releases).

## Reporting a vulnerability

Please **do not** open a public GitHub issue with exploit steps, private repository content, credentials, or live account data.

Use the repository's [private vulnerability reporting interface](https://github.com/rushairer/gouno-cli/security/advisories/new) when enabled. If the interface is unavailable, contact the repository maintainer through an established private channel before disclosing technical details publicly.

Include the affected version or commit, a minimal safe reproduction, the expected security boundary, and the potential impact. Do not include secrets or third-party personal data.

Security reports should be triaged privately before publishing a coordinated fix and advisory. See [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md) for release validation.
